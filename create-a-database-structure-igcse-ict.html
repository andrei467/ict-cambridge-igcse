How data is organised so it can be stored, found and updated without mistakes. This page covers the two types of database, then fields, data types and the keys that link tables together.

What is a database?

A database is a structured, persistent collection of data. It allows easy storage, retrieval and management of information. Electronic databases have key benefits:

  • Easier to add, delete, modify and update data
  • Data can be backed up and copied more easily
  • Multiple users, from multiple locations, can access the same database at the same time

There are two main types: flat file and relational.

Flat file database

A flat file database stores all data in a single table. It is simple and easy to understand, but causes data redundancy, inefficient storage and is harder to maintain.

Relational database

A relational database organises data into multiple tables. It uses keys to connect related data, which reduces data redundancy, makes efficient use of storage and is easier to maintain.

It solves the flat file problems: the tutor information moves to a new table, and a foreign key in the student table (TutorID) links each student to their tutor.

Fields & data types

A field is a single piece of data in a table (a column). make is a field in the cars table. A data type is the type of data a field can hold, and it is defined when designing the table.

Primary & foreign keys

A primary key is a unique field that identifies a record in a table. order_id is the primary key of orders, and customer_id is the primary key of customers.

A foreign key is a field in a table that refers to the primary key in another table. It links tables and creates relationships. In orders, customer_id is a foreign key: it links an order back to the customer who made it.
