Network Issues

Networks make sharing data easy — which is exactly why they need protecting. This page covers the risks in transferring data, how systems check you are who you say you are, how anti-malware software defends a device, and the different ways people meet remotely over a network.

Data transfer

Sharing data is a fundamental reason to use a network — electronic data is constantly moving between sender and receiver. The transfer of data on a network poses potential security risks, such as unauthorised access and data manipulation.

Common causes of data transfer security risks

CauseRisks
HackersExploit network weaknesses and access/delete/steal confidential data
Insider threatsIntentionally or unintentionally compromising network security policies, leading to data interception/theft
Social engineeringManipulating network users into giving away confidential information and/or clicking links which install malware, leading to the compromise of data

Passwords

Passwords are a digital lock to prevent unauthorised access to an account. They are often stored as an encrypted/ciphered text entry in a database, ensuring that even with unauthorised access to a database, a hacker would not be able to gain access to the individual passwords of users.

Passwords must be kept safe, which can be achieved by:

  • Using anti-spyware software to ensure "keyloggers" are not used
  • Periodically changing passwords to ensure they have not been compromised
  • Ensuring passwords are "strong": a mixture of upper/lower case, containing at least one number, containing at least one symbol, and a minimum of eight characters

Authentication

Authentication is the process of ensuring that a system is secure by asking the user to complete tasks to prove they are an authorised user of the system. Authentication is done because bots can submit data in online forms. Authentication can be done in several ways, including zero login & biometrics, magnetic stripe, smart cards, and physical & electronic tokens.

MethodDescriptionAdvantages & disadvantages
Zero login & biometricsAllows a user to login without using a username & password; uses biometric data (fingerprint, face, gestures) to create a profile of a user so they can log in without having to authenticate each timeConvenient for devices users need to log in to frequently, e.g. smartphones; if compromised, biometric data cannot be changed; biometric recognition can be less than perfect and lead to failed login attempts and user frustration
Magnetic stripeContains unique data used to authenticate a user, e.g. ID, name & date of birth; when swiped through a magnetic card reader, details are used to identify a userEasy and cheap to set up; cards can be used to access multiple systems; cards can be remotely deactivated; magnetic stripes can wear; card readers must be maintained; less secure than biometrics (easily copied)
Smart cardsEnhances a magnetic stripe card with the addition of a microchip to create a contactless card; the microchip stores additional information, such as a PIN, to add an extra layer of security; data is encryptedMore secure than magnetic stripe cards; multi-purpose; transactions can be much faster; more expensive to manufacture; lack of compatibility can cause inconvenience
Physical tokensA physical device used to authenticate a user remotely; the device generates a random one-time password (OTP) that a user must type in; banks may ask customers to insert their bank card into the device and use the OTP to access internet banking; OTPs change after a few minutesVery secure; inconvenient to the user, as they need a physical device, card and login credentials to access one site
Electronic tokensA software token generated by an app; the app generates OTPs; users authenticate in the app, e.g. fingerprint, and an OTP is generatedVery secure; more convenient

Anti-malware software

Anti-malware software is a term used to describe a combination of different software to prevent computers from being susceptible to viruses and other malicious software. The different software anti-malware includes: anti-virus, anti-spam, and anti-spyware.

How does anti-malware work?

  • Anti-malware scans through email attachments, websites and downloaded files to search for threats
  • Anti-malware software has a list of known malware signatures to block immediately if they try to access your device in any way
  • Anti-malware will also perform checks for updates to ensure the database of known issues is up to date
  • Anti-malware will quarantine infected files — quarantining files allows threats to be automatically deleted, and allows the user to determine if the file is a legitimate threat and not a false positive
  • Anti-malware can make use of heuristic checking — the identification of potential threats within a file from behavioural patterns and characteristics, rather than just relying on a database of known viruses

Video-conferencing

Video-conferencing is a way of enabling real-time audio and visual communication between geographically separated parties. It is ideal for small groups of users to create an engaging meeting experience, and is typically used for staff meetings and presentations.

Video-conferencing — real-time audio and visual communication over a network

To successfully host a video-conference, the following hardware is required: webcam, large output display (projector, screen, TV, etc.), microphone, speakers. Specialist software is also required, such as drivers to control the output of the webcam, and a codec to encode (compress) and decode (decompress) the data being transmitted.

AdvantagesDisadvantages
Convenience; cost saving; better for the environment; attendees do not have to travel to the event; anyone within the company can attend regardless of location; events can be held at short notice, as travel is not required; allows other members outside the organisation to attend easily without visiting on premises; some software allows record and playback, so members can review the meetingThe initial purchase of equipment can be costly; possible issues amongst employees working across different time zones; users may need training to use it effectively, which can take time and be costly; requires a strong and stable network connection; poor picture/sound quality caused by the speed of connection or quality of the hardware; delays (audio & visual) can disrupt the flow of the meeting

Audio-conferencing

Audio-conferencing is a way of enabling real-time audio only communication between geographically separated parties, using standard phone lines. To host an audio-conference, the host must be given a personal PIN and a participant PIN by the phone company. The host starts the conference using their personal PIN, and participants dial in and join using their participant PIN. Voice over Internet Protocol (VoIP) can also be used on computers to hold audio-conferences.

Audio-conferencing — the host dials in participants over standard phone lines

AdvantagesDisadvantages
Cheaper than video-conferencing, as less hardware is required; more accessible, as less training is needed for participants; gives participants the ability to focus only on voice and not get distracted by videoParticipants can lose focus due to lack of visual interaction; a lack of visual clues may lead to miscommunication; audio quality can be poor; does not suit collaboration

Web-conferencing

Web-conferencing is a way of enabling real-time audio and visual communication between geographically separated parties on the internet. It is ideal for large groups of users to create an engaging meeting experience, and is typically used for webinars, lectures, and presentations. To host a web-conference, the emphasis is placed on a high-speed, stable internet connection.

Web-conferencing — many participants join in a browser-based grid, over the internet

AdvantagesDisadvantages
Pre-shared/downloadable presentation notes or slides; participants can use instant messaging within the conference to ask questions; collaboration via virtual "whiteboards"; screen sharing/annotationsTechnical issues, usually relating to participant internet connections; security concerns and risk of data interception; distractions; some users may feel overloaded with information, which can lead to a lack of focus

Examiner tip: web-conferencing and video-conferencing are very similar, but the key difference is that video-conferencing focuses on face-to-face communication, while web-conferencing focuses on interaction and collaboration such as document sharing and whiteboards.
