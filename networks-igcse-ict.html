Networks

No computer is much use on its own. This page covers the hardware that connects devices together, how they talk to each other wirelessly, where data actually lives when it's "in the cloud," the different network environments a business might use, and the three types of network you need to know.

Router

The router is responsible for routing data packets between different networks — for example, sending internet traffic to the correct destination or device on your home network. The router connects networks together, joining local area networks (LANs) to the wider internet, which is itself a type of wide area network (WAN). It can manage and prioritise data traffic to help keep connections stable, and it assigns IP addresses to the devices on the network.

A router — connects a LAN to the wider WAN and assigns IP addresses

What are data packets?

Data packets are small "chunks" of data that make up a larger piece of data that has been broken down so it can be transmitted over the internet. Data can include text, images, audio, video, animations, or any combination of these. A data packet consists of:

Structure of a data packet — plus a packet number and checksums for error checking

A data packet also carries a packet number (e.g. "1 of 5") so the pieces can be reassembled in order, and error-checking information called checksums.

IP addresses

An IP (Internet Protocol) address is a unique identifier given to devices that communicate over the internet (WAN). IP addresses are dynamic — they can change. They make it possible to deliver data to the right device. A device connecting to a network is given an IP address; if it moves to a different network, its IP address will change.

IPv4

Internet Protocol version 4 is represented as 4 blocks of denary numbers between 0 and 255, separated by full stops. Each block is one byte (8 bits), so each address is 4 bytes (32 bits) in total.

IPv4 — over 4 billion unique addresses (2³²)

IPv4 provides over 4 billion unique addresses (2³²) — but with over 7 billion people and countless devices per person, a solution was needed.

IPv6

Internet Protocol version 6 is represented as 8 blocks of 4 hexadecimal digits, separated by colons. Each block is 2 bytes (16 bits), so each address is 16 bytes (128 bits) in total.

IPv6 — over one billion unique addresses for every person on the planet (2¹²⁸)

Network Interface Card (NIC)

The Network Interface Card (NIC) is required for a computer to connect to a network. A NIC can be both wired and wireless, and it allows a computer to send and receive data over a network.

Hub and switch

A hub connects multiple devices in a network. Hubs are "dumb" devices that pass on anything received on one connection to all other connections — all data is sent to all devices, which can lead to network inefficiencies and security issues.

A switch also connects multiple devices, but unlike a hub, it only sends data to the device it was intended for, which improves network efficiency. It does this using a lookup table: when a switch receives a data packet, it examines the destination MAC address of the packet and looks that address up in its table, then forwards the packet to the corresponding device.

A hub broadcasts to every device; a switch looks up the MAC address and sends to just one

MAC addresses

A MAC (Media Access Control) address is a unique identifier given to devices that communicate over a local area network (LAN). Unlike an IP address, a MAC address is static — it never changes. MAC addresses let switches efficiently forward data to the intended recipient. Any device containing a NIC has a MAC address assigned during manufacturing; if the device moves to a different network, its MAC address stays the same.

A MAC address is represented as 12 hexadecimal digits (48 bits), usually grouped in pairs. The first three pairs are the manufacturer ID number (OUI), and the last three pairs are the serial number of the network interface card. There are enough unique MAC addresses for roughly 281 trillion devices.

A MAC address — 12 hex digits, assigned once during manufacturing and never changed

Bridge

A network bridge is a device used to connect two local area networks (LANs) together to create one larger network. Unlike a switch or hub, bridges only connect local area networks together.

Each LAN's computers connect to their LAN, and the bridge joins the two LANs into one larger network

Wireless networks

A wireless network is a network where connections are made using radio waves to transmit data through the air. The most common types of wireless connection are Wi-Fi and Bluetooth.

Wi-Fi

Wi-Fi is a common standard for wireless networks, used in most homes and offices to connect laptops, tablets and smartphones. Using Wi-Fi, devices communicate with a hotspot or a wireless access point (WAP), which can be a standalone device or built into a router or switch. Wi-Fi may be preferred over Bluetooth when high-speed data transfer is required, long-range communication is required, or many devices need to be connected at the same time.

Wi-Fi — devices connect wirelessly to a wireless access point (WAP)

AdvantagesDisadvantages
Portability — easy to move around, limited only by rangeSpeed — slower data transfer than Ethernet
Cost — less expensive to set up and add new devicesSecurity — less secure than Ethernet
Compatibility — most devices have a built-in Wi-Fi adapterRange — relies on signal strength to the WAP; signals can be obstructed (up to 100m)

Bluetooth

Bluetooth is another common standard for wireless networks, common for connecting devices such as headphones, controllers, keyboards and mice. Bluetooth is typically used for a direct connection between two devices. When two devices pair, they both exchange a cryptographic key, which is used to generate a secret shared key that encrypts the data between them, creating a Wireless Personal Area Network (WPAN). Connected devices continuously change their transmitting frequency between 79 different channels to avoid interference and improve reliability — this is known as frequency hopping spread spectrum (FHSS).

Bluetooth pairs two devices directly and encrypts the connection between them

AdvantagesDisadvantages
Compatibility — ideal for personal devices and ad-hoc connectionsSpeed — very slow transfer speeds
Power — very low power consumptionSecurity — data can be intercepted by anyone in range
Range — short range (30m)

Cloud computing

Cloud storage describes long-term (secondary) storage of data that resides in a remote location, accessible only via a wide area network — the internet. Data is stored on remote servers, typically using magnetic storage (HDD), but increasingly using solid state (SSD). There are three types of cloud storage:

  • Public cloud — the customer and the cloud storage provider are different companies
  • Private cloud — the customer and the cloud storage provider are a single organisation
  • Hybrid cloud — combines both public and private options, keeping sensitive data private while using public cloud services for less sensitive information

Local storage sits on-site; cloud storage sits on a remote server, reached over the internet

Network environments

Internet

The Internet is a global network of networks. "Internet" is short for INTERconnected NETworks — multiple local area networks (LANs) connected to form a large wide area network (WAN). The Internet is the most well-known WAN, and is used to provide connectivity to the World Wide Web.

World Wide Web

The World Wide Web, or simply the web, is a collection of websites and web pages that are accessed using the internet. It was created in 1989 by Tim Berners-Lee, who envisioned it as a way to share and access information on a global scale. The web consists of interconnected documents and multimedia files stored on web servers around the world. Web pages are accessed using a web browser, which communicates with web servers to retrieve and display content.

The internet — a global network connecting many separate networks together

Intranet

An intranet is a network designed to work much like the internet, but it operates only within a local area network (LAN). Intranets provide companies with a secure platform to share information and resources exclusively with their employees. An intranet is a private network, and intranets sit behind a firewall to ensure that only authorised users can access it.

An intranet — a private network kept inside the organisation, behind a firewall

Advantages of an intranet over the internet:

  • Better bandwidth than the internet
  • Data is kept within the organisation
  • Less chance of hacking and attacks
  • Administrators can manage access to external sites and links

Extranet

An extranet is an extension to an intranet that allows authorised access from outside of the local area network. Once authenticated, users get managed access to network resources and/or information. An extranet is useful for companies who want to provide access to customers, clients or key stakeholders.

An extranet — an intranet that also lets specific outsiders in, once authenticated

Similarities between the internet, intranet and extranet: they are all web-based technologies; they allow users to access information remotely; they all use client-server architecture; they all use security measures such as authentication and encryption; and they all promote and facilitate information and resource sharing.

Network types

A network is two or more devices connected together with the purpose of sharing resources. There are three types of network: Local Area Networks (LANs), Wireless Local Area Networks (WLANs), and Wide Area Networks (WANs).

Local Area Network (LAN)

A local area network has a small geographical area (under 1 mile), and all of the hardware is owned by the company, organisation or household using it. LANs use unshielded twisted pair (UTP) cable, fibre optic cable, or wireless connections (Wi-Fi).

A LAN — wireless devices via a WAP, wired desktops via a switch, all on-site

AdvantagesDisadvantages
Allows centralised management of updates, backups and software installationsIf hardware fails, the network may not function properly or even at all
Can secure its devices with firewalls, antivirus software and other security features to prevent unauthorised accessNetworks are more prone to attacks than standalone computers
Allows users on the network to share resources such as printers and other peripheralsAccess to data and peripherals can be slow depending on network traffic
Allows users of the network to collaborate and share files and foldersRequires maintenance to ensure software is up to date, plus upgrades and backups, which can be costly

Wireless Local Area Network (WLAN)

A wireless local area network is a local area network where devices connect to the network wirelessly instead of using cables. Extra hardware — wireless access points (WAPs) or hotspots — is connected to the network so that users can connect using Wi-Fi.

AdvantagesDisadvantages
Allows users to connect anywhere in range of a WAP without needing additional hardware or wiringLimited coverage, which can be further affected by walls and other structures
Can be used in a variety of environments both indoors and outdoors, making them highly flexibleBandwidth speeds can become an issue in high-traffic areas
Additional wireless access points can be added relatively easily, increasing network coverageInterference from other devices can affect performance and connectivity
Access to peripherals such as printersVulnerable to security threats, as wireless signals can be intercepted

Wide Area Network (WAN)

A wide area network has a large geographical area (over 1 mile). WANs are a collection of LANs joined together, and the computers on a WAN are connected via routers. The hardware used to connect the networks together is not all owned by the company, organisation or household using it — for example, telephone lines owned by telecommunications companies. WANs use fibre optic cable, telephone lines and satellite links to connect the LANs together.

A WAN — separate LANs, often far apart, joined together via routers
