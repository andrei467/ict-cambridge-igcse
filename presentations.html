Presentations

How to create a presentation and use a master slide, edit it for its audience and purpose, and output it on screen or on paper — with a few activities at the end of each part.

Part 1 Create a presentation & master slides

Create a presentation

In the exam, the content for the presentation is provided in a rich text format (.rtf). The content can be imported using the New Slide button on the Home tab and selecting Slides from Outline.

Using a master slide

A master slide lets you control the design and layout of an entire presentation from one place. A master slide controls:

  • Colours
  • Fonts
  • Headers & footers
  • Positioning of objects
Examiner tips and tricksRemember to scroll to the top of the master slide window and select the first slide!

Auto slide numbering

  1. Select the master slide
  2. Insert a text box
  3. From the Insert tab, select Slide Number
  4. Close the master slide

Adding objects

  1. Select the master slide
  2. From the Insert tab, choose an object
  3. Position it on the slide
  4. Close the master slide

Formatting a master slide

  1. Select the master slide
  2. Make the desired changes (font & paragraph)
  3. Close the master slide
Examiner tips and tricksIf your changes are not visible after closing the master slide, highlight the text and use the Clear All Formatting button.

Part 2 Edit a presentation

Editing a presentation depends on the audience and purpose of the presentation. Common editing techniques are below.

Inserting, moving, deleting slides & applying slide layouts

Use the Home tab, in the Slides section.

Inserting objects

Using the Insert tab the user can choose to add:

  • Images
  • Videos
  • Charts etc.

Adding presenter notes

  • Presenter notes can be added to slides as prompts for the presenter for when delivering a presentation
  • Presenter notes usually contain key talking points
  • Using the View tab, in the Show section, select Notes

Inserting hyperlinks

  • Hyperlinks can be added to text or objects (images/videos etc.)
  • Select the text or object
  • Using the Insert tab, select Link

Inserting action buttons

An action button is a clickable object that enhances the interactivity of a presentation. Common actions include:

  • Navigation
  • Media playback
  • Run programs
  • Open links

Adding screen tips

  • Screen tips are short explanatory text that appear when you hover over an element on the slide
  • Screen tips provide additional details on hover

Adding alternative text (alt text)

Alternative text describes an image. Alt text is used for:

  • Accessibility – screen readers
  • To understand the content of an image

Applying consistent transitions & animations

  • Transitions can be used when moving between slides to create a more visually appealing flow
  • Animations can be used to add movement or emphasis to elements on a slide

Hiding slides

To hide a slide from a presentation without deleting it, right click on a slide and select Hide Slide.

Part 3 Output presentations

The two most common methods of outputting a presentation are on screen and printed.

On screen

On-screen presentations can be displayed in a variety of ways, including:

  • Looped on-screen carousel
  • Presenter controlled

Both options can be configured using the Slide Show tab and selecting Set Up Slide Show.

Printed

When printing a presentation, a variety of layouts can be selected, including:

  • Full page slides
  • Presenter notes
  • Handouts

Printing options can be found using the File tab and selecting Print.
