Components of Computer Systems

A computer works by taking an input, processing it, and producing an output — and every physical part of the system exists to do one of those three jobs. This page covers the CPU, memory, input and output devices, and how data is stored long-term.

CPU the brain of the computer

The Central Processing Unit (CPU) exists to fetch, decode and execute instructions. It takes an input, processes data, and produces an output — for example, clicking a gamepad button (input) is processed by the console's CPU (process) to move the player on screen (output).

The four key components

  • Arithmetic Logic Unit (ALU) — performs calculations and logical comparisons
  • Control Unit (CU) — directs and coordinates the CPU's operations
  • Cache — very fast, small memory holding data likely to be needed again soon
  • Registers — tiny, extremely fast storage locations for data being used right now

The fetch-execute cycle

The CPU runs through this cycle billions of times per second:

  • Fetch — the next instruction or data is fetched from RAM and brought to the CPU
  • Decode — the CPU works out what the instruction is actually asking for
  • Execute — the CPU carries out the instruction — e.g. performing a calculation, storing a result back in RAM, or fetching data from a different memory location

Internal memory RAM & ROM

Both RAM and ROM are types of primary storage — memory directly connected to the CPU — but they behave very differently.

FeatureRAMROM
StoresData & programs currently in useThe boot file (start-up instructions, including the BIOS)
CapacityVariable — can be increased to improve performanceFixed — cannot be increased
ContentsTemporaryPermanent
Read/WriteRead & writeRead only
Volatile?Volatile — contents lost when powered offNon-volatile — contents survive power loss
SpeedVery fast — much faster than secondary storageFast, but slower than RAM

Data and instructions must be copied from secondary storage into RAM before the CPU can use them. ROM is a small chip located on the motherboard.

Storage

A storage device reads from and writes to storage media, providing non-volatile secondary (backing) storage — used to store data and programs when they're not actively in RAM. There are three types:

TypeHow it stores dataGeneral strengths / weaknesses
MagneticUses magnetic polarity on a disk or tapeHigh capacity, low cost per GB — but has moving parts, so it's less durable and portable, and can be noisy
Solid stateUses electronic circuits, no moving partsVery fast, durable and portable — but expensive per GB with limited write cycles
OpticalUses a laser to burn pits and lands into a diskVery cheap and durable — but low capacity and slow access speed, and easily scratched

Don't confuse storage devices (the hardware, like a bookshelf) with storage media (what's stored in it, like the books) — e.g. a DVD (media) is read by a DVD drive (device).
