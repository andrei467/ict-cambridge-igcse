File Formats

Every file is stored in a format, and the format decides what it can hold and which software can open it. This page covers generic file formats, then image, video and audio files, then text, compressed and web files — with activities at the end of each part. Part 1 Generic file formats

File formats are the file types used to store the data in a file. They define the structure and organisation of the data in a file and determine which software can be used to read the contents of the file. A variety of file formats are used, depending on the type of file.

Generic and non-generic formats

  • Generic file formats are file types that are compatible and allow sharing between different devices and software programs
  • Non-generic files are types that require special software or hardware to be accessed

Generic file types are needed for these reasons:

  • Allowing the exchange of data across different types of applications
  • They are widely adopted and therefore can be accessed by many users or devices
  • Generic files can be created, edited and accessed across many different devices

Quick reference: characteristics & uses

The Compression column uses these three terms:

  • Lossy – makes the file smaller by permanently removing some data. The original cannot be restored exactly, but the quality is usually still acceptable
  • Lossless – makes the file smaller without losing any data, so the original can be restored exactly
  • Uncompressed – no compression at all, so the file keeps everything and is larger

Part 2 Image, video & audio files

Generic image files

  • Joint Photographic Expert Group (.jpg) — a widely used image format using lossy compression. It significantly reduces file size while keeping acceptable image quality, and is commonly used for storing and transmitting digital photographs
  • Portable Network Graphic (.png) — uses lossless compression. It preserves high-quality images while still giving small file sizes, and its transparency support allows graphics to be placed onto different backgrounds easily. Commonly used for web design, digital illustrations, logos and icons
  • Graphics Interchange Format (.gif) — used for short, animated images and simple graphics. It uses a lossless compression algorithm, keeps high image quality with small file sizes, and is used on social media, messaging apps and websites

Generic video files

  • Moving pictures expert group layer 4 (.mp4) — a multimedia container rather than a single file format that can be used for video, image and audio types. It uses advanced compression for high-quality playback, keeps file sizes relatively small and is popular for streaming and transferring videos online
  • QuickTime Movie (.mov) — a multimedia container format developed by Apple for storing video, audio and other media data. It keeps excellent image quality with smaller file sizes, suits online streaming and local playback, and is widely used in professional video editing, film production and multimedia projects

Generic audio files

  • Moving pictures expert group layer 3 (.mp3) — a popular, high-quality audio format that uses lossy compression. It gives a significant reduction in file size with minimal difference in sound quality, is compatible with a wide range of devices and audio streaming platforms, and became the standard format for digital music distribution
  • Waveform File Audio format (.wav) — an uncompressed audio format known for its high lossless quality. It preserves the original audio waveform and is commonly used in the music industry, broadcast and multimedia production

Part 3 Text, compressed & web files

Generic text files

  • Text (.txt) — used for storing plain text data: only human-readable text without any formatting or styling. Extensively supported across platforms and applications, and can be opened and edited using a word processor or basic text editor
  • Rich Text Format (.rtf) — used for storing formatted text documents that can contain different text styles, fonts, colours and other basic formatting. It can be opened and edited using a wide range of text editors and word processors, so it suits letters, reports and academic papers
  • Comma separated values (.csv) — a plain text file format for storing data in a structured manner: rows and columns, with each cell separated by a comma. Widely supported and easy to import and export between applications. Commonly used for data analysis and database management, and easily opened in spreadsheet software
  • Portable Document Format (.pdf) — retains the layout and formatting of documents across a range of platforms. Documents contain text, images, graphics and even interactive elements. Can be password-protected to stop unauthorised users editing, and allows a digital signature acting as a digital “ink signature”

Generic compressed files

  • Zip (.zip) — a container used for compression. It allows multiple files and folders to be compressed into a single, smaller-sized archive using lossless compression algorithms
  • Roshal archive (.rar) — a container used for compression, similar to .zip, but it uses a proprietary compression algorithm and generally gives higher compression ratios. Commonly used for sharing files over the internet and when space-saving is essential

Generic web development & browsing files

  • Hypertext Markup Language (.html) — a global file format used for creating and structuring web pages. It contains text-based code that defines the structure, layout and content of a webpage, is rendered by web browsers, and is used across many devices and platforms
  • Cascading Style Sheets (.css) — a file format that is attached to an HTML document and used to determine presentation and styling such as colours, fonts, layout and positioning. Widely used in web development to create responsive and attractive designs
