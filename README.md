# IGCSE ICT Interactive Revision

Interactive revision pages for **Cambridge IGCSE ICT** (Grade 9-10), made for my students at International Maarif School of Bucharest.

Each page has the theory, then tasks to check you've understood it: sorting activities, multiple-choice questions and written answers you mark yourself. Your score is shown on every page.

## The pages (in order)

1. Hardware & Software
2. Components of Computer Systems
3. Types of Computer & Emerging Technologies
4. Flashcards (covers pages 1–3)
5. Networks
6. Network Issues
7. Flashcards (covers pages 5–6)
8. Effects of Using IT
9. ICT Applications
    #more to be added

Use the **Previous / Next theory** buttons at the top of each page to move through them.

## How to use them

- Open any `.html` file in your browser. No installation or internet account is needed.
- **Keep all the files in the same folder**, or the Previous / Next buttons won't work.
- Your answers and flashcard progress are saved **on your own device**. Refreshing the page won't lose them. Use the **Reset** button to start again.
- On written questions, **try an answer first**. The model answer only appears once you've written something, and you decide whether you earned the point. Be honest, because the points are only for you.
